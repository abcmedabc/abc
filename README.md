# abc
První projekt

Malé hry v jednom souboru HTML, bez instalace a bez externích závislostí. Stačí otevřít v prohlížeči.

## Hry

| Hra | Popis | |
|---|---|---|
| 📱 **Mobily i cihly** | Tycoon o výrobě a prodeji telefonů, od Cihly 3310 až po Quantum X. Nastavuješ cenu, najímáš dělníky a návrháře a odemykáš vyšší parametry (RAM, úložiště, kamera, displej, baterie, procesor). Postup se ukládá do `localStorage`. | [▶ Hrát](https://abcmedabc.github.io/abc/mobily-i-cihly.html) |
| 📀 **DVD Screensaver** | Odrážející se logo DVD, které můžeš sestřelovat lodí. Ovládání: ←/→ nebo A/D, mezerník = střelba, klik = celá obrazovka. | [▶ Hrát](https://abcmedabc.github.io/abc/dvd.html) |

Zdrojové soubory: [mobily-i-cihly.html](mobily-i-cihly.html), [dvd.html](dvd.html).
