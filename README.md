## Mobily i cihly

Tycoon hra o výrobě a prodeji telefonů, od Cihly 3310 až po Quantum X. Nastavuješ cenu, najímáš dělníky a návrháře a odemykáš vyšší parametry (RAM, úložiště, kamera, displej, baterie, procesor).

▶ [Hrát hru](https://abcmedabc.github.io/abc/mobily-i-cihly.html) (hlavní stránka: [mobily-i-cihly.html](mobily-i-cihly.html))

Hra je jediný soubor bez externích závislostí, takže funguje i po otevření lokálně v prohlížeči. Postup se ukládá do `localStorage`.
